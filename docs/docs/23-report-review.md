# 报告审查与发布

审查中心按一份已保存的报告建立检查记录，保存当时的报告正文、检查结果和审查规则。项目创建者及工作区 OWNER / ADMIN 可以运行检查、保存规则和签署；其他有项目访问权限的成员可以查看。

## 使用流程

1. 在报告页面保存正文和引用，点击“建立行动项”。系统按正文行动项表格或清单的顺序列出任务，逐项确认名称、验收标准、实际负责人和截止日期。
2. 点击“按顺序建立”，进入该报告的行动项看板。重复导入不会重复建项；文档中的虚拟责任人需要分派为实际工作区成员。没有可识别清单时可手工建立关联任务。
3. 负责人开始处理，完成后填写证据与执行记录并“提交验收”。项目创建者或工作区管理员填写验收意见，选择通过关闭或退回修改。待验收不算完成，文档中写“已完成”也不会直接获得验收状态。
4. 发布前置任务关闭后，更新报告中的进展和结论，点击“返回报告审查”。按需调整引用、数字、冲突和外部来源规则，保存后运行当前版本检查。
5. 处理阻断项，打开来源核对待人工核验的内容。正文快照可与当前保存的正文切换查看。未建立的报告任务或未验收的发布前置任务会阻断；明确设为“发布后跟进”的任务需人工确认。
6. 逐项确认人工核验内容，填写审查意见，签署通过或退回修改。退回后可建立带来源报告、审查编号及问题说明的修复行动项，完成后重新检查。
7. 通过后前往报告页面发布。每次签署不可覆盖；需要更正结论时重新运行检查并签署新记录。行动项验收不会自动批准或改写报告。

没有报告时，页面提供准备报告的入口。旧版只统计资源数量的检查记录仍可查看，但需要重新检查当前报告才能签署。

## 检查内容及边界

| 检查 | 自动检查范围 | 人工确认内容 |
| --- | --- | --- |
| 报告正文 | 空正文阻断 | 正文是否完整回答项目问题 |
| 引用与事实 | 启用后，缺少引用记录、标记及链接时阻断 | 出处真实、位置可定位，且支持对应结论 |
| 数字与日期 | 提取阿拉伯数字周边片段 | 单位、日期、条件、原始值及计算；中文数字也需留意 |
| 冲突与假设 | 按规则建立核验项 | 矛盾来源、假设和资料缺口是否说明 |
| 外部来源 | 提取正文与结论中的网页链接 | 机构、发布时间、访问时间及适用范围 |
| 分析运行 | 关联运行未完成或不存在时阻断 | 已完成运行的结论是否成立 |
| 项目资料 | 展示索引状态，有未完成资料时待核验 | 是否影响本报告依据 |
| 检索回归 | 有未运行或未通过用例时待核验 | 是否影响本报告；命中资料不等于答案正确 |
| 交付范围 | 始终建立人工核验项 | 问题覆盖、事实与推断区分、风险及后续责任 |
| 行动项落实与验收 | 未建立的报告任务或未验收的发布前置任务阻断；发布后跟进任务待核验 | 完成证据是否满足验收标准，剩余跟进是否影响交付 |

没有关联分析、资料或检索用例时，相应检查可跳过。没有阿拉伯数字或网页链接不表示内容已被证明正确。检查不调用模型或自动访问网页；事实核验需要审查人完成。

## 签署和发布约束

- 有阻断项不能通过；所有待人工核验项目确认且审查意见非空后才能通过。退回同样要求意见。
- 只有该报告最新的有效检查记录能够签署。报告内容、版本、引用、规则、资料状态、检索回归状态、关联分析或关联行动项变化会使旧记录失效。
- 历史检查始终显示当时保存的正文和意见；失效记录及旧正文不会被新内容覆盖。
- 后端发布接口也校验最新签署和内容指纹，不能只修改前端状态绕过。
- 编辑已发布报告的内容会退回草稿；对已发布报告执行新的退回签署也会退回草稿。
- 重新打开已验收的发布前置任务，或为已发布报告增加未完成的前置任务，也会将报告退回草稿，必须再次验收和审查。
- 行动项保留来源报告版本及建项时原文。执行证据和验收意见写入审计记录；旧版“已完成”但没有验收凭据的记录，需要补齐标准、重新打开并提交验收。
- 已有历史发布记录不批量改写；后续发布操作采用上述约束。草稿仍可以导出。

## 手工验收清单

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 无报告项目打开审查中心 | 显示准备报告入口，不生成空检查 |
| 2 | 选择有正文和来源的报告并运行检查 | 生成绑定该报告版本的新记录，显示逐项明细 |
| 3 | 不勾选人工核验项或不填写意见 | 不能签署通过 |
| 4 | 核验完成并填写意见后通过，刷新页面 | 结论、签署人、时间、意见和勾选状态保留，原记录不可修改 |
| 5 | 从已通过记录进入报告页发布 | 发布成功 |
| 6 | 编辑已发布报告正文并保存 | 报告变为草稿，旧记录标记失效，再次发布被拦截 |
| 7 | 开启引用要求，对无引用报告运行检查 | 有阻断项，不能通过；可填写意见退回 |
| 8 | 退回后建立修复行动项 | 打开行动项草稿，保留报告、审查编号及问题说明 |
| 9 | 修改规则或依据后尝试签署旧记录 | 后端拒绝，提示重新检查；已填写意见保留 |
| 10 | 重查后切换查看历史记录及正文 | 历史意见和旧正文不被新记录覆盖 |
| 11 | 使用非创建者且非管理员的项目成员查看 | 可看明细和历史，不能修改规则、运行或签署 |
| 12 | 手机宽度查看，模拟接口失败及切换项目 | 无横向溢出；可重试，失败保留输入，旧项目响应不覆盖新项目 |

- V34 迁移在本地开发数据库成功应用，后端已重启；前端代理验证码接口和 AI 健康检查通过。
