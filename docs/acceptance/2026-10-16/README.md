# Shinkou Insight 完整流程测试包

版本：2026-10-16。所有业务、人物、数据和隔离口令均为虚构，用于验证系统功能。

## 先跑主流程
1. 打开01-项目与测试指令.md，新建独立测试项目并保存规划。使用已配置可用模型，关闭联网。
2. 只向“知识库”上传 knowledge-base 目录的6份Markdown，等待全部索引成功。不要把整个测试包一次性上传。
3. 在检索Playground先验证XQ-03的276、300、120秒和66秒，再执行标准问答与完整分析指令。
4. 按02-逐步验收.md依次核对报告、审查签署、发布和行动项，在验收记录表填写实际结果。
5. 最后在单独测试项目执行旧版、现行冲突、注入和缺资料场景；隔离文件按目录分别放项目B和工作区B。

主场景固定结果：准确率92%、知识覆盖96%、严重错误率1%、检索耗时降低45%、周活跃率75%、成本139000元、预算余11000元。
八项量化门槛满足，但推广条件还有三项待关闭；正确报告应提出受限内部验证及后续行动，不能批准正式对外上线。

## 文件分工
| 路径 | 用途 | 放置方式 |
| --- | --- | --- |
| knowledge-base/ | 6份有完整事实来源的主知识资料 | 仅这6份先上传主项目知识库 |
| raw-data/ | 300条合成测量、20人活跃和5项成本原始JSON | 离线复算或上传文件库；默认不进入主知识库 |
| questions/ | 8条检索用例、20道问答及预期 | 测试人员参考；按页面字段人工录入，不上传知识库 |
| negative/ | 旧版、同口径冲突、文档内指令、空文档 | 按异常用例分开上传，避免污染主场景 |
| isolation/ | 另项目、另工作区的隔离口令样本 | 严格按目录放置，不能上传主项目 |
| project-setup.json | 规划字段的结构化备份 | 人工复制字段，不是自动项目导入接口 |
| expected-results.json | 可机读固定答案 | 仅供核对，不上传知识库 |
| acceptance-cases.json | 40项用例与初始状态 | 可用于后续比较，不代表已经测试通过 |
| outputs/01a13a11-429b-7f62-9a82-79cc007901a7/端到端验收记录.xlsx | 可填写的40项验收记录 | 测完回传此表及截图/运行编号 |
| 04-反馈模板.md | 缺陷反馈模板 | 逐个问题填写 |
| manifest.json | 所有文件的大小及SHA256 | 校验分发文件是否完整 |

## 预期范围
本包覆盖导入、索引、检索、引用、计算、聊天、多轮、检索回归、智能分析、报告编辑/导出、审查/失效/发布门禁、行动项和隔离场景。

之前2026-10-14的全功能验收包保留未改动，可以作为扩展功能清单使用。本包使用当前菜单与审查流程。
