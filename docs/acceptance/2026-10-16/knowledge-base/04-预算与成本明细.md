## 现行成本口径
本表为 2026-10-14 确认的六周结算口径，覆盖整个 20 人试点，币种为人民币，全部含税。
预算上限为 150000 元。以下每一项已经是六周合计，不是每月、每人或每周单价；不得再次乘以 6、20 或任何月份数。

| 费用编号 | 项目 | 六周含税合计（元） |
| --- | --- | ---: |
| C01 | 平台与模型调用 | 36000 |
| C02 | 接入与检索集成 | 48000 |
| C03 | 问题集标注和质量核验 | 24000 |
| C04 | 培训与试用支持 | 19000 |
| C05 | 运维与监控 | 12000 |

总成本计算为 36000 + 48000 + 24000 + 19000 + 12000 = 139000 元。
预算剩余金额为 150000 - 139000 = 11000 元。预算使用比例为 139000 / 150000，约 92.67%。
平均每名试点用户的六周分摊成本为 139000 / 20 = 6950 元；这只是分摊指标，不是收费价格，也不需要再加回总成本。
本表没有提供正式推广后的月度单价或未来生产成本估算。
