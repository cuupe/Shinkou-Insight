# 星桥试点验收指标与统计口径

项目：星桥知识助手试点验收
文档编号：XQ-02
版本：V1.0
资料截止日：2026-10-16
性质：完全虚构的系统验收资料。本文模拟记录不是现实业务结果。

## 验收门槛
| 指标 | 门槛 | 口径 |
| --- | --- | --- |
| 样本数 | 不少于 300 条 | 去重后的合成业务测试问题 |
| 答案准确率 | 不低于 90% | 正确回答数 / 全部测试问题数 |
| 资料可定位覆盖率 | 不低于 95% | 能定位有效知识依据的问题数 / 全部测试问题数 |
| 平均检索耗时降低比例 | 不低于 40% | (人工基线平均秒数 - 助手平均秒数) / 人工基线平均秒数 |
| 严重错误回答率 | 严格低于 2% | 严重错误问题数 / 全部测试问题数，分母不是错误回答数 |
| 试点用户周活跃率 | 不低于 70% | 指定观察周内活跃用户数 / 20 名试点用户 |
| 试点周期 | 不超过 6 周 | 42 个自然日，起止日均计入 |
| 六周总成本 | 不高于 150000 元 | 含税人民币六周全量成本，不能按人或按月再次乘算 |

## 判定规则
指标必须使用 XQ-03 的实际模拟测量值计算，不能直接把本表中的门槛当成已经达到的结果。
“低于 2%”不包含 2%；“不低于 90%”包含 90%；“不高于 150000 元”包含 150000 元。
指标全部达标不等于允许对外上线。推广还必须满足 XQ-05 中的权限撤销、运行责任和新增样本复测条件。
本轮没有规定生产并发量、峰值 QPS、生产 SLA、外部客户满意度、长期 ROI 或当前供应商价格。这些数值不能从试点结果推测。
